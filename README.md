1\. Repository (Repo): A repository is a storage location where a project's files, code, and change history are kept. It helps developers organize and manage their projects.

2\. Commit: A commit is a saved record of changes made to a project. It usually includes a short message describing what was changed, making it easier to track the project's progress.

3\. Branch: A branch is a separate version of a project where developers can work on new features or make changes without affecting the main version of the project.

4\. Merge: Merging is the process of combining changes from one branch into another, usually after the changes have been completed and tested.

5\. Version Control: Version control is a system that keeps track of changes made to files over time. It allows developers to view previous versions, undo mistakes, and work together on the same project.
